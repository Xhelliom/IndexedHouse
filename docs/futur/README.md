# Futur

Idées mûries mais non engagées. Aucune date, aucune promesse.

Une idée entre ici dès qu'elle est formulée, pour ne pas être perdue et pour ne
pas polluer le plan en cours. Elle en sort le jour où elle devient un lot dans
`plan/roadmap.md`.

Ce qui compte dans une note de ce dossier : les **prérequis**. Beaucoup d'idées
ne coûtent presque rien si la donnée nécessaire est collectée dès le départ, et
deviennent irréalisables sinon. C'est la seule chose qui doit remonter jusqu'aux
décisions du moment.

|---|---|---|

est sorti pour devenir le lot 4 du plan.
